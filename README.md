# BBEEARR — the plush tap room

Статичный одностраничник (один index.html + assets/). Ничего собирать не нужно.

Как задеплоить: залить папку в репозиторий на GitHub → Vercel → Add New Project → Import → Deploy (build command не нужен).
Контракт и ссылку на X вписать в блоке SETTINGS в самом верху index.html.
